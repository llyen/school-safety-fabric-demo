# Schools and safety: a national layer on Microsoft Fabric

A demo scenario for civil protection and crisis management on Microsoft Fabric. It adds a national view on top of a sample school incident reporting app built in Power Apps: all 16 Polish voivodeships, drill-down to county and school, detection of coordinated waves of hoax reports, and an escalation decision path. All documentation, data and UI are in Polish.

Polish version (main documentation): [README.md](README.md).

The question it answers: is this a wave of false alarms or a real threat, and where do I need to act first?

## Data

All data is synthetic, generated by `generate_datasets.py` with `seed=42`. Schools, report numbers, texts and call volumes are generated. Only voivodeship names are real and they serve as an aggregation level. Counties, cities and municipalities have code names (for example "powiat P-0201", "Miasto M-1402", "Gmina G-0201002"), and school names combine a type, a number and such a coded locality, so no report is attributed to an existing school or place. No report describes a real event, and the texts contain no operational detail of any attack.

## Quick start

```powershell
cd ol-szkoly-bezpieczenstwo
pip install -r requirements.txt
python generate_datasets.py
python simulate_realtime.py --dry-run --speed 3600
python notebooks\01_priority_scoring.py
```

Fabric deployment: see `SETUP_FABRIC.md` and `deploy/README.md`. You need `az login`, a Fabric capacity and its ID (`deploy\01_create_workspace.ps1 -CapacityId <CAPACITY_ID>`).

The app:

```powershell
cd fabric-app\pulpit-szkol
npm ci
npm test
npm run build
```
